# ScamShield: Digital Rights Protection for India 🛡️

An AI-powered scam detection tool making digital safety accessible to all Indians—regardless of language, literacy, or technical background.

---

## 🚨 The Problem

India faces a rising digital fraud crisis:
- **₹18,000+ crores** lost to online scams annually (2024)
- **60% of Indians** lack basic digital literacy
- Elderly and non-English speakers are most vulnerable
- Millions have **no way to verify suspicious messages** before losing their savings

## ✅ The Solution

**ScamShield** instantly detects scams across multiple formats:

### Core Features
- **📱 Message Analysis** — Paste SMS/WhatsApp text; get instant risk score
- **🖼️ Image OCR** — Upload screenshots; detects fraud in Tamil & English
- **🎙️ Voice Recognition** — Record audio or paste transcript; analyzes for red flags
- **👵 Family Mode** — Simplified interface for elderly users
- **📊 Risk Scoring** — 0-100 scale with visual indicators
- **🔴 Threat Breakdown** — Shows EXACTLY which red flags triggered

### What Makes It Different
✅ **Tamil + English support** — Reaches 60M+ non-English speakers  
✅ **No backend required** — Runs entirely in browser (privacy + accessibility)  
✅ **Works offline** — No internet needed for core analysis  
✅ **Mobile-responsive** — Works on any device  
✅ **Free & open-source** — Justice should be accessible to everyone

## 🏗️ How It Works

### Scam Detection Engine
ScamShield analyzes text against **15+ scam categories**:
- UPI & Payment Fraud
- Job Scams
- Govt Impersonation (PAN, Aadhar, etc.)
- Prize/Lottery Scams
- Fake Schemes
- Short Links (URL masking)
- And more...

### Risk Scoring Algorithm
```
Risk Score = Sum of matched pattern weights
0-50:   ⚪ Safe (No obvious signs)
50-150: ⚠️  Suspicious (Verify with official channels)
150+:   🚨 High-risk (Likely scam)
```

### User Guidance
For **high-risk detections**, ScamShield provides:
- ✅ Immediate action steps (STOP, DON'T click, DON'T share OTP)
- ✅ Links to verify with official sources (.gov.in domains)
- ✅ Cybercrime reporting links (1930 helpline, cybercrime.gov.in)

---

## 🛠️ Tech Stack

- **Frontend:** HTML5 + Vanilla JavaScript (zero dependencies)
- **OCR:** Tesseract.js (reads text in Tamil + English)
- **Voice:** Web Speech API (speech-to-text)
- **Storage:** Browser localStorage (no data sent to servers)
- **Design:** Custom CSS with accessibility-first approach

### Why No Backend?
1. **Privacy** — All analysis happens locally
2. **Accessibility** — Works on any device with a browser
3. **Reliability** — No server dependence; works offline
4. **Cost** — Completely free to run and maintain
